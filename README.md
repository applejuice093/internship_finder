# Internship Finder: AI-Based Internship Recommendation Engine

A Streamlit app built for the PM Internship Scheme use case. A candidate
uploads a resume, the app pulls out their technical skills, checks them with
a short multiple-choice quiz (generated by Google Gemini), and then
recommends the internships whose descriptions best match the profile.

## How it works

1. **Profile and resume**: pick your highest education and preferred
   location, then upload a resume (PDF or DOCX).
2. **Skill extraction**: the resume text is scanned for known skills
   (Python, C++, SQL, React, Flask, MongoDB, Docker, AWS, Linux, Excel and
   so on; see `TARGET_SKILLS` in `core.py`).
3. **Skill assessment**: Gemini writes 3 multiple-choice questions about
   those skills. Without an API key, or if the AI call fails, a built-in
   question bank is used and the app tells you so.
4. **Matching**: postings and the candidate profile are turned into TF-IDF
   vectors and ranked by cosine similarity. Matching preferred location or
   education each add a small soft boost (`PROFILE_MATCH_BOOST`, still
   capped at 99). The top 3 are shown with shared skills and an apply link.

## Quick start

Requires Python 3.10 or newer.

```bash
git clone https://github.com/applejuice093/internship_finder.git
cd internship_finder
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Then open http://localhost:8501.

## Configuration

All settings are optional. Without them the app runs in offline mode with
the built-in questions and sample internships.

| Setting | Where | Purpose |
| --- | --- | --- |
| `GEMINI_API_KEY` | environment variable or `.streamlit/secrets.toml` | Enables AI-generated quiz questions. Get a key at https://aistudio.google.com/app/apikey |
| `GEMINI_MODEL` | environment variable | Gemini model to use (default `gemini-2.5-flash`) |
| `INTERNSHIP_DB_URL` | environment variable | URL of a JSON array of postings (for example a GitHub Gist "Raw" link) to use instead of the samples |

To use Streamlit secrets:

```bash
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
# then edit .streamlit/secrets.toml and paste your key
```

`secrets.toml` and `.env` are git-ignored. Never commit an API key.

### Internship data format

`INTERNSHIP_DB_URL` must return a JSON list of objects with these fields
(see `BUILTIN_INTERNSHIPS` in `core.py` for examples):

```json
[
  {
    "title": "Junior Backend Intern",
    "company": "TechGram",
    "location": "Remote",
    "education": "Graduate",
    "skills": ["python", "sql", "api"],
    "description": "Build backend APIs using Python and SQL.",
    "apply_url": "https://pminternship.mca.gov.in/"
  }
]
```

Postings missing a field, or whose `apply_url` is not an absolute `http://`
or `https://` URL, are skipped. If the URL can't be loaded (or the payload
exceeds 2 MB), the app shows a warning and falls back to the six built-in
sample internships.

## Project structure

| Path | Purpose |
| --- | --- |
| `app.py` | Streamlit UI: upload, quiz and results pages |
| `core.py` | Pure logic: resume reading, skill extraction, question parsing and validation, internship loading, TF-IDF matching |
| `tests/` | pytest suite, including end-to-end tests that drive the app with Streamlit's `AppTest` |
| `.streamlit/secrets.toml.example` | Template for the Gemini API key |

## Development

```bash
pip install -r requirements-dev.txt
pytest          # unit + end-to-end tests (no API key or network needed)
ruff check .    # lint
```

## Resume upload limits

Resumes larger than **5 MB** are rejected before parsing (`MAX_RESUME_BYTES`
in `core.py`) so oversized PDFs cannot hang the extractors.

## Scoring

Match percentages start from TF-IDF cosine similarity (scaled and offset),
then receive `PROFILE_MATCH_BOOST` (+5) for each of location and education
that equals the candidate profile. The final value is capped at 99. They
are similarity scores, not a probability of being selected.

## Limitations

- Image-only (scanned) PDFs contain no text, so no skills can be found. The
  app warns when this happens.
- The built-in sample set currently has **6** internships covering backend,
  frontend, data/cloud, Flask/MongoDB, HTML/CSS and Redis/ops profiles.
